# Operating Systems Labs
A collection of university assignments and projects for the Operating Systems course, using MINIX 2.0.3.

## Topics
- Kernel compilation and system calls
- Process scheduling
- Synchronization using semaphores and monitors
- Memory management
- File systems

Projects are implemented primarily in C and shell scripting, and include source code, test cases, and documentation where applicable.

## Purpose
To practice operating systems concepts through hands-on programming and system-level experiments using MINIX 2.0.3.
